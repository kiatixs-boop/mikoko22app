# mikoko-moster — Contexto del proyecto

Sistema de monedero cripto con 22 bases de datos (BD0-BD21).

## Stack
- Node.js Express (server.js, puerto 5000)
- Vite + React + Tailwind (puerto 3001)
- SQLite (22 tablas BD0-BD21 en `.obsidian/mikoko-moster/`)

## Reglas locales
- NO enviar datos financieros fuera del sistema
- NO modificar `.obsidian/` (es la base de datos)
- Los cambios se registran en `../cerebro-maestro-ia/08-REGISTRO-IA/LOG.md`
